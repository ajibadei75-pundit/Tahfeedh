NOOR HIFZ — deploy guide
========================
1. Go to https://app.netlify.com/projects/noor-hifz/deploys
2. Drag noor-hifz-site.zip (or this whole folder) onto the deploy area.
3. Open https://noor-hifz.netlify.app  (hard refresh once: Ctrl/Cmd+Shift+R)

FIRST RUN
- The FIRST account you create becomes the Super Admin.
- Super Admin -> Madrasahs -> "New madrasah" -> share the Admin / Teacher / Student codes.
- Students & teachers: Sign up -> "I have a madrasah code".

INSTALL ON ANDROID
- Open the site in Chrome -> an "Install Noor Hifz" bar appears (or menu ⋮ -> Install app).
